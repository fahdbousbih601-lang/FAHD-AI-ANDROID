# FAHD AI — مشروع Android أولي

## ما الذي يحتويه؟
- مشروع Android Studio بلغة Kotlin.
- واجهة عربية متجاوبة داخل WebView.
- اقتراحات للمحادثة وردود تجريبية.
- اسم التطبيق FAHD AI ومعرّف التطبيق `com.fahd.ai`.

## مهم
هذا نموذج أولي فقط. الإجابات ليست متصلة بنموذج ذكاء اصطناعي حقيقي. لا تنشر التطبيق على أنه مساعد AI كامل قبل ربطه بخدمة حقيقية واختباره.

## كيف تفتحه؟
1. على الكمبيوتر، نزّل Android Studio من الموقع الرسمي: https://developer.android.com/studio
2. فكّ ضغط `FAHD_AI_Android.zip`.
3. افتح Android Studio واختر **Open** ثم مجلد `FAHD_AI_Android`.
4. وافق على تثبيت/مزامنة Gradle وانتظر حتى تكتمل.
5. وصّل هاتف Android مع تفعيل Developer options وUSB debugging، أو استخدم المحاكي.
6. اضغط Run ▶ لتجربة التطبيق.

## الخطوات التالية
1. ربط آمن بخادم خلفي ومزوّد AI؛ لا تضع API key في التطبيق.
2. إضافة سياسة خصوصية وحذف البيانات غير اللازمة.
3. اختبار الأداء والتوافق.
4. إعداد أيقونة نهائية ولقطات شاشة ووصف المتجر.
5. إنشاء حساب Google Play Console ودفع رسوم التسجيل الحالية (عادةً 25 دولارًا لمرة واحدة)، وإتمام متطلبات الاختبار والتحقق التي تظهر لحسابك.
6. إضافة الإعلانات فقط بعد ضبط الخصوصية وسياسات Google Play وAdMob.

## حدود ما تم إنجازه
الملفات المصدرية جاهزة كبداية، لكن لم يتم إنشاء APK موقع للنشر، ولم يتم ربط AI أو الإعلانات. يلزم بناء المشروع واختباره على جهازك.
